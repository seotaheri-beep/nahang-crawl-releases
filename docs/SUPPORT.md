# گزارش اشکال / Reporting a problem

گزارش‌های فاقد اطلاعات خصوصی را در [Issues ریپوی انتشار](https://github.com/seotaheri-beep/nahang-crawl-releases/issues) ثبت کنید. این صفحه عمومی است؛ پیش از ارسال، متن و پیوست را بازبینی کنید. برنامه گزارشی را خودکار ارسال نمی‌کند.

Use the public [release repository’s Issues](https://github.com/seotaheri-beep/nahang-crawl-releases/issues) for reports without private information. Review text and attachments before posting. The app does not automatically submit a report.

## پیش از گزارش / Before reporting

1. نسخهٔ پایین پنجره و راهنما ← Debug را بررسی کنید. / Check the footer version and Help → Debug.
2. مراحل را با یک سایت مجاز و تا حد امکان یک نمونهٔ کوچک تکرار کنید. / Reproduce using an authorised site and a small example where possible.
3. رفتار مورد انتظار و واقعی را جدا بنویسید. / Separate expected and actual behaviour.
4. Save Logs یک ZIP محلی می‌سازد. پیش از پیوست، محتوا را بررسی کنید؛ نیازی به ارسال کل پایگاه داده یا پشتیبان خصوصی نیست. / Save Logs creates a local ZIP. Review it before attaching it; do not upload your full private database or backup.

## قالب / Template

```text
Version / نسخه:
Windows version and architecture / نسخه و معماری ویندوز:
Storage mode: Database or RAM / حالت ذخیره:
Rendering: HTML or JavaScript / حالت رندر:
Steps to reproduce / مراحل بازتولید:
1.
2.
Expected result / نتیجهٔ مورد انتظار:
Actual result and error text / نتیجهٔ واقعی و متن خطا:
Can it be reproduced with a public or synthetic example? / نمونهٔ عمومی یا مصنوعی:
Attachments reviewed for private information? / پیوست‌ها بازبینی شده‌اند:
```

رمز، API key، توکن، کوکی، پروفایل Authentication، فایل OAuth، vault، `Local State`، URL خصوصی و محتوای محرمانه را عمومی نکنید. اگر گزارش فقط با اطلاعات حساس ممکن است، ابتدا بدون آن اطلاعات موضوع را مطرح کنید و یک مسیر خصوصی تأییدشده از نگهدارنده بخواهید؛ این پروژه در این سند نشانی ایمیل شخصی یا کانال خصوصی تأییدنشده معرفی نمی‌کند.

Do not publish passwords, keys, tokens, cookies, authentication profiles, OAuth files, credential vaults, `Local State`, private URLs or confidential page content. If sensitive information is essential, describe the problem without it first and request a verified private channel from the maintainer. This guide does not invent a private support address.
