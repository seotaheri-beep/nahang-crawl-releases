# حریم خصوصی و جریان داده

این سند رفتار فنی نسخهٔ فعلی Nahang Crawl را توضیح می‌دهد؛ [English](PRIVACY.en.md). تاریخ بازبینی: ۲۰۲۶-۱۰-۲۷. این سند محلی هنوز نشانی عمومی تأییدشدهٔ سیاست OAuth در Google نیست.

## دادهٔ روی دستگاه

پایگاه دادهٔ خزش، صف‌ها، URLها، یافته‌ها، محتوای استخراج‌شده، HTML/DOM/PDF و تصویرهای فعال‌شده، تنظیمات، تاریخچه و آمار استفاده در فضای محلی برنامه یا محل ذخیرهٔ انتخابی شما قرار می‌گیرند. فایل خروجی و پشتیبان در محل انتخاب‌شده ذخیره می‌شوند. آمار استفاده برای نمایش Summary/Usage محلی ثبت می‌شود و ارسال خودکار ندارد.

Database هنگام کار ثبت می‌شود؛ در RAM ذخیرهٔ جلسه با اقدام شماست. گزارش‌ها می‌توانند snapshot موقت روی دیسک بسازند. حذف خزش الزاماً فایل‌های خروجی مستقل، پشتیبان، فایل موقت یا آمار تجمیعی قبلی را حذف نمی‌کند. مسیر و روش بازیابی را در [راهنما](QUICK_START.fa.md) ببینید. Retention قابل تنظیم است و پیش‌فرض Never دارد؛ خروجی‌هایی که خودتان جدا ذخیره کرده‌اید مشمول آن نیستند.

رمزها، کلیدها، توکن‌های Google و داده‌های احراز هویت با امکانات ذخیره‌سازی امن سیستم نگهداری می‌شوند؛ دسترس‌پذیری آن به سیستم و پروفایل مرتبط وابسته است. پروفایل محلی و پشتیبان را مانند دادهٔ خصوصی نگهداری کنید. فایل‌های خروجی، HTML و پشتیبان می‌توانند دادهٔ خصوصی سایت داشته باشند؛ رمزگذاری vault به معنی رمزگذاری تمام فایل خزش نیست.

## داده‌ای که از دستگاه خارج می‌شود

| اقدام | مقصد و داده |
|---|---|
| خزش HTML یا JavaScript و دریافت منابع | سایت‌های مجاز طبق تنظیمات؛ URL، User-Agent، IP اتصال و هدر/کوکی یا دادهٔ ورود لازم برای درخواست انتخاب‌شده |
| Google Search Console / GA4 | سرویس Google با مجوز فقط‌خواندنی کاربر؛ Property، بازه، ابعاد/فیلتر لازم و credential اتصال؛ گزارش پاسخ روی دستگاه ذخیره می‌شود |
| PageSpeed | Google PageSpeed؛ URL عمومی و راهبرد بررسی، و کلید فقط اگر تنظیم شده باشد |
| Gemini | Google؛ دستور تحلیل و بخش محدودشدهٔ متن صفحه، عنوان و URL به‌همراه کلید شخصی؛ تنها با اجرای تحلیل |
| Moz | Moz؛ URL انتخاب‌شده و کلید شخصی برای دریافت معیار |
| Ollama و Embeddings | مدل محلی روی localhost/loopback؛ متن انتخاب‌شده برای استنتاج یا تولید بردار. مدل ابری از این مسیر پذیرفته نمی‌شود |
| Check for Updates | GitHub و میزبان دریافت فایل رسمی؛ درخواست Release/asset و اطلاعات معمول اتصال شبکه. بررسی خودکار اختیاری و پیش‌فرض خاموش است |
| اعلان ایمیلی اختیاری | حساب ایمیل/SMTP انتخاب‌شده و گیرندگان تنظیم‌شده؛ پیام پایان خزش و پیوست‌های انتخابی |
| MCP | مشتری دارای مجوز اتصال، پس از شروع سرور؛ داده‌ها و نتایجی که ابزارهای مجاز در اختیار آن مشتری می‌گذارند |

سیاست‌های ارائه‌دهندگان بیرونی برای داده‌ای که به آن‌ها می‌فرستید برقرار است. Proxy و گواهی‌های مورد اعتماد انتخابی شما نیز مسیر و اعتبارسنجی اتصال را تحت تأثیر قرار می‌دهند. اتصال سرویس اختیاری برای خزش معمول لازم نیست.

## عیب‌یابی و اشتراک

لاگ فنی به رخدادها و فیلدهای مجاز محدود می‌شود و چرخش/سقف دارد؛ بدنهٔ صفحات، رمزها، کلیدها، کوکی‌ها و هدرهای ورود عمداً در رخدادهای عادی ثبت نمی‌شوند. سطح لاگ از Debug Options قابل تغییر است. Save Logs فایل محلی می‌سازد؛ ارسال خودکار به پشتیبانی ندارد. Share در Usage Stats نیز فایل CSV/JSON محلی می‌سازد. پیش از اشتراک، محتوا را بررسی کنید.

CSV، فایل خزش، HTML، عکس صفحه و پشتیبان می‌توانند URL، دادهٔ صفحه یا اطلاعات خصوصی پروژه داشته باشند. از قرار دادن آن‌ها در گزارش عمومی خودداری کنید مگر اینکه برای انتشارشان مجوز داشته باشید. [روش گزارش اشکال بدون اطلاعات حساس](SUPPORT.md).

قطع اتصال Google در برنامه، credential محلی را حذف می‌کند؛ برای لغو مجوز در خود Google از تنظیمات حساب Google استفاده کنید. این دو اقدام یکسان نیستند. پس از تغییر محل ذخیره‌سازی یا حذف یک خزش، کپی‌های مستقلی را که ساخته‌اید خودتان مدیریت کنید.
