# Nahang Crawl — Windows x64

خزندهٔ دسکتاپ سئوی فنی با کنترل‌های اصلی فارسی و انگلیسی. نسخهٔ بتا یک نسخهٔ واحد است و فعال‌سازی لایسنس لازم ندارد.

A desktop technical SEO crawler with Persian and English main controls. The beta is one edition and requires no licence activation.

**[دریافت بتا / Download 1.0.0-beta.1](https://github.com/seotaheri-beep/nahang-crawl-releases/releases/tag/v1.0.0-beta.1)** · [همهٔ انتشارها / All releases](https://github.com/seotaheri-beep/nahang-crawl-releases/releases)

## نصب و ارتقا / Install and upgrade

1. Setup.exe یا ZIP مخصوص Windows x64 را از صفحهٔ همان انتشار انتخاب کنید. / Choose its Windows x64 Setup or portable ZIP.
2. SHA-256 را با فایل SHA256SUMS.txt همان انتشار تطبیق دهید. / Check its SHA-256 against the release checksum file.
3. پیش از ارتقا، کار فعال را ذخیره و برنامه را ببندید؛ پوشهٔ داده را حفظ کنید. / Save work, close the app and preserve the data directory before upgrading.
4. Setup را اجرا کنید؛ برای ZIP همهٔ فایل‌ها را در پوشه‌ای تازه استخراج و NahangCrawl.exe را باز کنید. / Run Setup, or extract the entire ZIP into a new folder and run NahangCrawl.exe.
5. برای راهنمای آفلاین F1 بزنید؛ شروع خزش معمولی حساب Google یا API لازم ندارد. / Press F1 for help; ordinary crawling needs no Google account or API.

## وضعیت بتا / Beta status

بسته‌ها **بدون امضای دیجیتال** و runtime همراه برنامه **Electron 46 alpha** است. این نسخهٔ پایدار نیست؛ Windows ممکن است هشدار دهد یا طبق سیاست دستگاه اجرای آن را متوقف کند. برخی یافته‌ها و ابزارهای تخصصی هنوز فارسی‌اند.

Packages are **unsigned** and bundle **Electron 46 alpha**. This is not a stable release; Windows may warn or block execution according to device policy. Some specialist tools and findings remain in Persian.

این بتا کلاینت پیش‌فرض عمومی Google را همراه ندارد؛ کاربران پیشرفته می‌توانند Desktop OAuth خود را وارد کنند. سرویس‌های اختیاری نیازمند دسترسی و سهمیهٔ خود ارائه‌دهنده‌اند. این مخزن برای فایل‌های انتشار و مستندات عمومی است؛ کد منبع در این مخزن منتشر نمی‌شود.

This beta ships no default public Google OAuth client. Advanced users may import their own Desktop OAuth configuration. Optional services require provider access and quotas. This repository contains release files and public documentation, not the application's source code.

## آپدیت و بازخورد / Updates and feedback

از Help → Check for Updates استفاده کنید؛ بررسی خودکار اختیاری و پیش‌فرض خاموش است. نسخه‌های آلفا و بتا می‌توانند پیش‌انتشار جدیدتر را ببینند؛ نسخهٔ پایدار فقط انتشار پایدار را می‌بیند. دریافت فایل با اقدام کاربر انجام می‌شود و نصب خودکار نیست.

Use Help → Check for Updates. Automatic checks are optional and off by default. Alpha/beta users can receive newer prereleases; stable users see stable releases only. Downloads are an explicit user action and are not automatically installed.

بازخورد را با قالب‌های [Issues](https://github.com/seotaheri-beep/nahang-crawl-releases/issues/new/choose) ثبت کنید. قبل از ارسال، اطلاعات خصوصی، کلید، کوکی و URL محرمانه را حذف کنید. آمار استفاده محلی است؛ برنامه گزارشی را خودکار ارسال نمی‌کند.

Use the issue templates for feedback. Review reports for private data, credentials, cookies and confidential URLs before posting. Usage statistics stay local; reports are not automatically submitted.
