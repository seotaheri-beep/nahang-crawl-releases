# Nahang Crawl releases

Public Windows downloads and release notes for **Nahang Crawl**.

Download a version from [Releases](https://github.com/seotaheri-beep/nahang-crawl-releases/releases).

Nahang Crawl checks this repository from **Help → Check for Updates**. The optional **Auto Check for Updates** setting checks once per day while the application is open. Downloading a new version is an explicit user action.

The update checker follows semantic version order. Alpha installations can receive newer alpha or stable releases; stable installations receive stable releases. A Git tag on its own is not an update: publish a GitHub Release with a Windows ZIP or installer asset.

Portable Windows releases are ZIP files. Extract into a new folder, save any active crawl, and launch the new executable. Keep the application's data directory to retain projects, preferences, and locally recorded usage statistics.

Usage statistics stay on the computer. The update checker requests only public release metadata and the selected download from GitHub.
